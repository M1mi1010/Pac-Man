# Pacman
Pac-Man is a faithful Unity recreation of the 1980 arcade classic. The core gameplay revolves around navigating the maze, collecting pellets and avoiding the four ghosts — Blinky, Pinky, Inky and Clyde — each of which follows its own distinct chase behaviour rather than simply moving randomly. Blinky pursues Pac-Man directly, Pinky targets several tiles ahead of Pac-Man's current direction, while Inky and Clyde use more unpredictable patterns that keep the player on edge.
Power pellets temporarily flip the dynamic, sending the ghosts into a frightened state where they can be hunted down for bonus points. The project involved implementing pathfinding logic for each ghost, managing game state transitions between normal and frightened modes, and recreating the feel of the original's movement and collision system within Unity's 2D physics engine.
